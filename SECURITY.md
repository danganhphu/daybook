# Security

Please report a vulnerability privately, through GitHub: the **Security** tab of this repository, then **Report a
vulnerability**. Do not open a public issue for it.

Most worth reporting: reading or changing data without signing in, taking over an account or a session, or using a
setup link that should no longer work. How sign-in is meant to behave is in
[docs/product/design.md](docs/product/design.md), "Sign-in", and the rules the code keeps are in
[docs/architecture/domain.md](docs/architecture/domain.md), "Access".

This is a personal project with one maintainer. Replies are best effort.
